`FLUX.1 Fill [dev]` is a 12 billion parameter rectified flow transformer capable of advanced inpainting and outpainting from images and masks.
For more information, please visit our [website](https://blackforestlabs.ai/).

# Key Features
1. Advanced inpainting and outpainting capabilities for seamless image editing.
2. Natural integration of edits with existing images.
3. High-quality fill results that blend naturally with the source image.
4. Trained using guidance distillation, making `FLUX.1 Fill [dev]` more efficient.
5. Open weights to drive new scientific research, and empower artists to develop innovative workflows.
6. Generated outputs can be used for personal, scientific, and commercial purposes, as described in the [FLUX.1 \[dev\] Non-Commercial License](https://github.com/black-forest-labs/flux/blob/main/model_licenses/LICENSE-FLUX1-dev).

# Usage
We provide a reference implementation of `FLUX.1 Fill [dev]`, as well as sampling code, in a dedicated [github repository](https://github.com/black-forest-labs/flux).
Developers and creatives looking to build on top of `FLUX.1 Fill [dev]` are encouraged to use this as a starting point.

For detailed usage instructions, please see the [fill documentation](https://github.com/black-forest-labs/flux/blob/main/docs/fill.md).

# Limitations
- This model is not intended or able to provide factual information.
- As a statistical model this checkpoint might amplify existing societal biases.
- The model may fail to generate output that matches the prompts.
- Prompt following is heavily influenced by the prompting-style.
- Fill quality depends on the quality and clarity of the input mask.
